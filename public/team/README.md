# Team photos

Save each person's photo in this folder, named as below, then refresh the
page — it shows automatically. Any of .jpeg, .jpg, .png or .webp works, so
save it however your computer already saved it. No resizing or cropping
needed: the site crops every photo into a circle, whatever size it is.

No photo yet? Their initials show instead, so nothing looks broken.

Name each file exactly like this (lowercase), plus its extension:

- david
- nombulela       (spelled this way in the file name)
- nobuhle
- michelle        (photo still to come)
- simba
- chieta          (this is Chiedza's file)
- olerato
- ndaedzo

Group photo (wide works best):

- group-photo

To change a name, role, bio, skill tag or GitHub link, edit the `TEAM_MEMBERS`
list in `src/routes/index.tsx` (search for "TEAM_MEMBERS"). One block per
person.
